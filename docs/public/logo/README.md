# Cosy Logo — Symbol Assets

Fan mark: tiga kartu identik (tilt -8°) — back outline Ocean Blue, mid outline Cyan, front solid Brand Orange.
Satu sumber, banyak output. Logo only — wordmark/lockup tidak termasuk set ini.

## Warna
| Role | HEX | Kontras vs putih |
|---|---|---|
| Ocean Blue (back outline) | `#1864AB` | 6.09:1 |
| Cyan (mid outline) | `#22B8CF` | 2.38:1 |
| Brand Orange (front solid) | `#E8590C` | 3.58:1 |

## File
| File | Pakai untuk |
|---|---|
| `logo-symbol.svg` | Master — ukuran ≥32px |
| `logo-symbol-small.svg` | Favicon/app-icon ≤32px (3-tone filled, pemisah putih) |
| `logo-symbol-black.svg` | One-colour hitam (print/fax/grayscale dokumen) |
| `logo-symbol-white.svg` | Di atas background gelap |
| `logo-symbol-mono-e8590c.svg` | One-colour brand (watermark, tekstur) |
| `png/logo-symbol-{16..512}.png` | PNG siap pakai per ukuran |
| `png/logo-symbol-small-{16,32,48}.png` | PNG small-cut |
| `favicon.ico` / `favicon.svg` / `favicon-*.png` | Favicon situs (3-tone) |
| `icon-192.png` / `icon-512.png` | PWA any-mask (transparan) |
| `maskable-512.png` | PWA maskable — full-bleed warm-white, safe-zone 22% |
| `apple-touch-icon.png` | iOS home screen 180px (bg putih) |

## Aturan cepat
- Clear space = tinggi satu kartu di sekeliling mark.
- Urutan tone tidak boleh ditukar: terang di belakang → padat di depan.
- Konteks one-colour/greyscale → pakai orange solid (`-mono-e8590c` / `-black`), bukan 3-tone.
- Jangan: ubah tilt, tambah kartu ke-4, gradient, drop shadow.
